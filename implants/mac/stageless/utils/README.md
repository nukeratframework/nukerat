# Overview

Shared stageless utilities for mac: globals, task registry, crypto transport, networking, and host metadata collection.

## Directories

- `/actions`: Fingerprint and prep before the beacon loop
- `/crypt`: C2 payload encryption helpers
- `/general`: Strings and metadata builders
- `/macapi`: Darwin API handlers used across capabilities
- `/network`: HTTP, TCP, relay packets, SOCKS, port forward
- `/obf`: Compile-time string obfuscation
- `/tasks`: Task buffer, threading, and dispatch helpers
