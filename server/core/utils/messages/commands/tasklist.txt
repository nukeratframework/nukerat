ABOUT
    List running processes on the target machine.

USAGE:
    tasklist [<args>]

ARGUMENTS:
    <args>              Optional ps args on Linux and macOS. Ignored on Windows.

EXAMPLES:
    tasklist
    tasklist aux

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    EXAMPLE:
    tasklist -w 60
