ABOUT
    Read the contents of a file. Output is truncated if it exceeds
    25 megabytes.

USAGE:
    cat <path>

ARGUMENTS:
    <path>              File to read.

EXAMPLES:
    cat /etc/hosts
    cat C:\Windows\System32\drivers\etc\hosts

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    EXAMPLE:
    cat -w 120 C:\Temp\large.log
