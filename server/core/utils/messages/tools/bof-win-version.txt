ABOUT
    Queries the registry and system APIs to provide a concise but detailed overview of the
    Windows installation.

USAGE:
    bof-win-version

EXAMPLES:
    bof-win-version

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-win-version -w 60
    bof-win-version -bg
