ABOUT
    Change user password. Supports standard LDAP (389) with signing/sealing
    and LDAPS (636).
USAGE:
    bof-set-password --- {user} {newpass} [-ou {path}] [-dc {ip}] [--ldaps]

EXAMPLES:
    bof-set-password --- {user} {newpass} [-ou {path}] [-dc {ip}] [--ldaps]

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-set-password -w 60 --- {user} {newpass} [-ou {path}] [-dc {ip}] [--ldaps]
