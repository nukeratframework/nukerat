ABOUT
    Create a new group. Supports standard LDAP (389) with signing/sealing
    and LDAPS (636).
USAGE:
    bof-add-group --- {name} [-ou {path}] [-dc {ip}] [--ldaps]

EXAMPLES:
    bof-add-group --- {name} [-ou {path}] [-dc {ip}] [--ldaps]

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-add-group -w 60 --- {name} [-ou {path}] [-dc {ip}] [--ldaps]
