ABOUT
    Creates or deletes a scheduled task via registry only, without triggering Windows events 4698 and 106. Requires NT AUTHORITY\SYSTEM.

USAGE:
    bof-ghost-task --- <ARGC> <HOSTNAME> <OPERATION> [args...]

    ARGC is the total argument count passed to the BOF (including hostname and operation).

ARGUMENTS:

    HOSTNAME      localhost or remote computer name

    OPERATION     add or delete

    TASKNAME      Scheduled task name

    PROGRAM       Program to execute (add only)

    ARGUMENT      Program arguments (add only)

    USERNAME      User account for the task (add only)

    SCHEDULETYPE  second, daily, weekly, or logon (add only)

    TIME/SECOND   Frequency or time for the trigger (add only)

    DAY           Days for weekly trigger (add only)

EXAMPLES:

    bof-ghost-task --- 8 localhost add demo cmd.exe "/c notepad.exe" LAB\Administrator daily 20:37

    bof-ghost-task --- 4 localhost delete demo

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-ghost-task -w 60 --- localhost add demo cmd.exe "/c notepad.exe" LAB\Administrator daily 20:37
