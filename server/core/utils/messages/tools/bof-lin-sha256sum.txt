ABOUT
    (linux) Compute sha-256 hash.

USAGE:
    bof-lin-sha256sum --- <target>

ARGUMENTS:
    target              File path(s)

EXAMPLES:
    bof-lin-sha256sum --- <target>

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-lin-sha256sum -w 60 --- <target>
