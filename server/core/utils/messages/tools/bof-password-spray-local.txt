ABOUT
    Validate a single local username and password against a list of target hostnames using SMB authentication (IPC$).

USAGE:
    bof-password-spray-local --- <file> <username> <password> <timer> <jitter>

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-password-spray-local -w 60 --- <file> <username> <password> <timer> <jitter>
