ABOUT
    (linux) Print current date/time.

USAGE:
    bof-lin-date --- [format]

ARGUMENTS:
    format              +format string

EXAMPLES:
    bof-lin-date
NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-lin-date -w 60 --- [format]
