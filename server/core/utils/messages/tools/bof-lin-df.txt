ABOUT
    (linux) Disk space usage.

USAGE:
    bof-lin-df --- [path]

ARGUMENTS:
    path                Mount point or path

EXAMPLES:
    bof-lin-df
NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-lin-df -w 60 --- [path]
