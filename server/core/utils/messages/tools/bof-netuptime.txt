ABOUT
    Return information about the boot time on the local or remote computer

USAGE:
    bof-netuptime --- <hostname>

EXAMPLES:
    bof-netuptime --- dc01.corp.local

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-netuptime -w 60 --- dc01.corp.local
