ABOUT
    Starts an existing Windows service.

USAGE:
    bof-sc-start --- <SVCNAME> [HOSTNAME]

ARGUMENTS:

    SVCNAME    Service name

    HOSTNAME   Optional remote host

EXAMPLES:

    bof-sc-start --- MySvc

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-sc-start -w 60 --- MySvc
