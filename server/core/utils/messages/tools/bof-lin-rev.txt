ABOUT
    (linux) Reverse lines of a file.

USAGE:
    bof-lin-rev --- <file>

ARGUMENTS:
    file                Input file

Supports pipe chaining with other BusyBOF tools.

EXAMPLES:
    bof-lin-rev --- <file>

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-lin-rev -w 60 --- <file>
