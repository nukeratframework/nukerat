ABOUT
    Replace attribute value. Supports standard LDAP (389) with
    signing/sealing and LDAPS (636).
USAGE:
    bof-set-attribute --- {target} {attr} {value} [-ou {path}] [-dc {ip}] [--ldaps]

EXAMPLES:
    bof-set-attribute --- {target} {attr} {value} [-ou {path}] [-dc {ip}] [--ldaps]

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-set-attribute -w 60 --- {target} {attr} {value} [-ou {path}] [-dc {ip}] [--ldaps]
