ABOUT
    Change a user password via kpasswd.
USAGE:
    bof-kerbeus-changepw --- /ticket:BASE64 /new:PASSWORD [/dc:DC] [/targetuser:USER] [/targetdomain:DOMAIN]

EXAMPLES:
    bof-kerbeus-changepw --- /ticket:BASE64 /new:NewP@ss123

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-kerbeus-changepw -w 60 --- /ticket:BASE64 /new:NewP@ss123
