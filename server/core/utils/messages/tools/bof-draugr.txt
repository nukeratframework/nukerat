ABOUT
    Draugr stack spoofing with indirect syscalls. Allocates memory via
    NtAllocateVirtualMemory, copies shellcode with NtWriteVirtualMemory,
    sets PAGE_EXECUTE_READ with NtProtectVirtualMemory, and runs it in a
    new thread via NtCreateThreadEx using synthetic stack frames.

USAGE:
    bof-draugr --- <shellcode path>

EXAMPLES:
    bof-draugr --- /path/to/payload.bin
    bof-draugr -bg --- /path/to/payload.bin

NOTES:
    Use -bg when the shellcode blocks or spawns a long-running process,
    otherwise the BOF may time out waiting for output.

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-draugr -w 60 --- /path/to/payload.bin
    bof-draugr -bg --- /path/to/payload.bin
