ABOUT
    List process modules (DLL). Target current process if PID is empty. Complement to driversigs to determine if our process was injected by AV/EDR

USAGE:
    bof-listmods --- [opt:pid]

EXAMPLES:
    bof-listmods    bof-listmods --- 1234

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-listmods -w 60 --- 1234
