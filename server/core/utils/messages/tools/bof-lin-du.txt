ABOUT
    (linux) Estimate disk usage.

USAGE:
    bof-lin-du --- [path] [options]

ARGUMENTS:
    path                Target path (default: .)
    options             Flags: s (summary only) (choices: s)

Supports pipe chaining with other BusyBOF tools.

EXAMPLES:
    bof-lin-du
NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-lin-du -w 60 --- [path] [options]
