ABOUT
    Hash filename using md5

USAGE:
    bof-md5 --- <filename>

EXAMPLES:
    bof-md5 --- C:\Windows\System32\ntdll.dll

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-md5 -w 60 --- C:\Windows\System32\ntdll.dll
