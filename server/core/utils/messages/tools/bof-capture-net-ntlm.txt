ABOUT
    Capture the NetNTLMv2 hash of the current user. This is done by simulating a NTLM authentication exchange between a client and server to capture the NetNTLMv2 hash.

USAGE:
    bof-capture-net-ntlm --- (no arguments)

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-capture-net-ntlm -w 60 --- (no arguments)
