ABOUT
    Deletes a registry key or value on the local or remote system.

USAGE:
    bof-reg-delete --- <hive> <path> [value]
    bof-reg-delete --- --host <hostname> <hive> <path> [value]

ARGUMENTS:
    hive                Numeric hive code: HKCR=0 HKCU=1 HKLM=2 HKU=3 HKCC=5
    path                Registry key path
    value               Optional value name (omit to delete entire key)
    --host              Optional remote computer name

EXAMPLES:
    bof-reg-delete --- 1 Software\NukeratBenchTest
    bof-reg-delete --- 1 Software\Test ValueName
    bof-reg-delete --- --host kingslanding 1 Software\NukeratBenchTest

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-reg-delete -w 60 --- 1 Software\NukeratBenchTest
