ABOUT
    Proof of concept RDP session hijack utility. Takes control of disconnected
    interactive login sessions using WTSConnectSession and WTSDisconnectSession.

USAGE:
    net-sharp-rdp-hijack --- [options]

OPTIONS:
    --tsquery=<host>     Query host for RDP/TS session information
    --session=<ID>       Target session identifier
    --password=<pass>    Session user password if known
    --console            Redirect session to console instead of current session
    --shadow             Shadow an active session (experimental)
    --disconnect         Disconnect an active remote session

EXAMPLES:
    net-sharp-rdp-hijack --- --tsquery=localhost
    net-sharp-rdp-hijack --- --session=6
    net-sharp-rdp-hijack --- --session=2 --console
    net-sharp-rdp-hijack --- --session=4 --password=P@ssw0rd
    net-sharp-rdp-hijack --- --session=3 --disconnect

NOTES:
    Session hijacking requires elevated (administrator) context.
    Without password, impersonates NT AUTHORITY\\SYSTEM.
