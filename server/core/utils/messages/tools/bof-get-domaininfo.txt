ABOUT
    Query domain information from rootDSE. Supports standard LDAP (389) with
    signing/sealing and LDAPS (636).
USAGE:
    bof-get-domaininfo --- [-dc {ip}] [--ldaps]

EXAMPLES:
    bof-get-domaininfo --- [-dc {ip}] [--ldaps]

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-get-domaininfo -w 60 --- [-dc {ip}] [--ldaps]
