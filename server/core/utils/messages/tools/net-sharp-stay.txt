ABOUT
    .NET persistence toolkit supporting elevated and non elevated registry keys,
    scheduled tasks, services, WMI event subscriptions, COM handler hijacks, and LNK
    backdoors.

USAGE:
    net-sharp-stay --- action=<action> [options]

ELEVATED ACTIONS:
    ElevatedRegistryKey       HKLM/HKCU Run key persistence
    ElevatedUserInitKey       UserInit registry key
    ScheduledTask             Create elevated scheduled task
    CreateService             Create Windows service
    WMIEventSub               WMI event subscription

NON ELEVATED ACTIONS:
    UserRegistryKey           HKCU Run key persistence
    UserInitMprLogonScriptKey InitMprLogonScript registry key
    SchTaskCOMHijack          Scheduled task COM handler hijack
    JunctionFolder            Junction folder DLL hijack

MISC ACTIONS:
    ScheduledTaskAction       Add action to existing scheduled task
    NewLNK                    Create new LNK file
    BackdoorLNK               Backdoor existing LNK
    ListTaskNames             List scheduled task names
    ListScheduledTasks        List scheduled tasks
    ListRunningServices       List running services
    GetScheduledTaskCOMHandler Get COM handlers for scheduled tasks

COMMON OPTIONS:
    command       Executable path or command
    keyname       Registry value name
    keypath       Registry key path
    taskname      Scheduled task name
    servicename   Service name
    clsid         COM CLSID for hijack
    dllpath       DLL path for hijack
    cleanup=true  Remove persistence artifact

EXAMPLES:
    net-sharp-stay --- action=ElevatedRegistryKey keyname=Debug keypath=HKCU:Software\\Microsoft\\Windows\\CurrentVersion\\Run command="C:\\Windows\\temp\\fun.exe"
    net-sharp-stay --- action=ScheduledTask taskname=TestTask command="C:\\windows\\temp\\file.exe" runasuser=user1 triggertype=logon
    net-sharp-stay --- action=CreateService servicename=TestService command="C:\\Windows\\temp\\fun.exe"
