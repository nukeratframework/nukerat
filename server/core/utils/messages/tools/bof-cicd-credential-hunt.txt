ABOUT
    Finds common CI/CD, cloud, and developer credential artifacts in the current Windows
    user profile. Reports path and size by default. .gitconfig and .ssh/config are
    classified as configuration, not credential artifacts.

USAGE:
    bof-cicd-credential-hunt --- [verbose]

ARGUMENTS:
    verbose             Optional. Pass verbose or -verbose for bounded content previews

EXAMPLES:
    bof-cicd-credential-hunt
    bof-cicd-credential-hunt --- verbose

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-cicd-credential-hunt -w 60 --- verbose
