ABOUT
    Execute LDAP searches (NOTE: specify *,ntsecuritydescriptor as attribute parameter if you want all attributes + base64 encoded ACL of the objects, this can then be resolved using BOFHound. Could possibly break pagination, although everything seemed fine during testing.)

USAGE:
    bof-ldapsearch --- <query> [attributes] [count] [scope] [hostname] [dn] [ldaps]

ARGUMENTS:
    scope    1=base, 2=one-level, 3=subtree (default 0 returns no results)

EXAMPLES:
    bof-ldapsearch --- (objectClass=user) cn 0 3
    bof-ldapsearch --- (objectClass=computer) *,ntsecuritydescriptor 0 3

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-ldapsearch -w 60 --- (objectClass=user)
