ABOUT
    Persistence tool that creates hidden registry Run keys using NtSetValueKey with a null
    byte prefix in the UNICODE_STRING key value name, evading standard registry enumeration.

USAGE:
    net-sharp-hide --- action=<action> [options]

OPTIONS:
    action       create or delete
    keyvalue     Path to executable for create (required for create)
    arguments    Optional arguments for the executable

EXAMPLES:
    net-sharp-hide --- action=create keyvalue="C:\Windows\Temp\payload.exe"
    net-sharp-hide --- action=create keyvalue="C:\Windows\Temp\payload.exe" arguments="arg1 arg2"
    net-sharp-hide --- action=delete

NOTES:
    Creates hidden Run key at HKCU or HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
    depending on current user context.
