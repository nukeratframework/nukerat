ABOUT
    Validate single password against multiple accounts using LDAP, LDAPS, GC, or GCS simple bind authentication.

USAGE:
    bof-password-spray-a-d --- <file> <password> <domain> <dc> <proto> <timer> <jitter>

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-password-spray-a-d -w 60 --- <file> <password> <domain> <dc> <proto> <timer> <jitter>
