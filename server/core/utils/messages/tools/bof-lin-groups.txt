ABOUT
    (linux) Print group memberships.

USAGE:
    bof-lin-groups --- [user]

ARGUMENTS:
    user                Username (default: current user)

EXAMPLES:
    bof-lin-groups
NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-lin-groups -w 60 --- [user]
