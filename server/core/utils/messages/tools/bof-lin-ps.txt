ABOUT
    (linux) List processes.

USAGE:
    bof-lin-ps [flags]

ARGUMENTS:
    flags               Optional process listing flags: a, u, x, f, w

EXAMPLES:
    bof-lin-ps
    bof-lin-ps --- aux
NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-lin-ps -w 60
    bof-lin-ps -bg
