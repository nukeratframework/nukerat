ABOUT
    Return logged on user SIDs by enumerating HKEY_USERS. BOFHound compatible

USAGE:
    bof-regsession --- [opt:hostname]

EXAMPLES:
    bof-regsession
NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-regsession -w 60 --- [opt:hostname]
