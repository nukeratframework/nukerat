ABOUT
    .NET tool that enumerates domain controllers and checks LDAP signing/channel binding settings
    to assess relay attack risk. Tests both LDAP and LDAPS on each discovered DC.

USAGE:
    net-ldap-sign-check-dotnet    net-ldap-sign-check-dotnet --- -domain <domain> -user <user> -password <pass> [-dc-ip <ip>]

OPTIONS:
    -domain      Domain FQDN (optional, uses current domain if omitted)
    -user        Domain username for authenticated DC enumeration
    -password    Password for authenticated DC enumeration
    -dc-ip       Specific DC IP for DNS queries

EXAMPLES:
    net-ldap-sign-check-dotnet    net-ldap-sign-check-dotnet --- -domain lab.local -user domain_user -password Password123! -dc-ip 192.168.1.10
