ABOUT
    Checks current token privileges for abuse potential.
USAGE:
    bof-privkit-token-check --- (no arguments)

EXAMPLES:
    bof-privkit-token-check
NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-privkit-token-check -w 60 --- (no arguments)
