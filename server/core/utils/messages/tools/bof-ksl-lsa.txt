ABOUT
    Extracts credentials from LSASS memory using the KslD.sys BYOVD physical
    memory read primitive. Does not call OpenProcess, NtReadVirtualMemory,
    or MiniDumpWriteDump on lsass. Extracts MSV1_0 NT hashes, WDigest
    cleartext (when enabled), and LSA encryption keys. Requires
    administrative privileges.
USAGE:
    bof-ksl-lsa
EXAMPLES:
    bof-ksl-lsa
NOTES:
    Uses the vulnerable KslD.sys driver from System32\drivers\ (333,216 bytes). Credential Guard
    blocks domain credential extraction but local accounts and LSA secrets may still be recovered.

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-ksl-lsa -w 60
    bof-ksl-lsa -bg
