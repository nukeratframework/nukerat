ABOUT
    (linux) Show network interfaces.

USAGE:
    bof-lin-ifconfig --- [interface]

ARGUMENTS:
    interface           Interface name

EXAMPLES:
    bof-lin-ifconfig
NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-lin-ifconfig -w 60 --- [interface]
