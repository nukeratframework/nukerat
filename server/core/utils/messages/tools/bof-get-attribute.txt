ABOUT
    Read specific LDAP attribute. Supports standard LDAP (389) with
    signing/sealing and LDAPS (636).
USAGE:
    bof-get-attribute --- {target} {attribute} [-ou {path}] [-dc {ip}] [--ldaps]

EXAMPLES:
    bof-get-attribute --- {target} {attribute} [-ou {path}] [-dc {ip}] [--ldaps]

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    bof-get-attribute -w 60 --- {target} {attribute} [-ou {path}] [-dc {ip}] [--ldaps]
