ABOUT
    Registry only credential dumper extracting SAM hashes and secrets from
    HKLM\\SECURITY\\Policy\\Secrets. Requires SeBackupPrivilege only (no SYSTEM).

USAGE:
    bof-silentharvest
EXAMPLES:
    bof-silentharvest
NOTES:
    Enable SeBackupPrivilege before running (getprivs or equivalent).
    Supports Win 10/2016+ with AES encryption. Does not support legacy RC4.
