ABOUT
    C# EDR/AV detection tool. Checks running processes, loaded DLLs, install directories,
    services, and drivers for known defensive products including hidden EDR via metadata.

USAGE:
    net-sharp-edr-checker
EXAMPLES:
    net-sharp-edr-checker
NOTES:
    Checks processes, module loads in current process, common install paths, services,
    and drivers for AV, EDR, and logging tool signatures.
