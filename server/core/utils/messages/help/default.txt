INJECTION
-------------------------------------------------------------------------------------------------------------------------

    migrate       migrate 4919 [--alloc <mode>]                        Inject implant shellcode into a process

    spawn         spawn -t cmd.exe --- <args>                          Spawn process and capture output
                  spawn suspend -t C:\Windows\System32\notepad.exe     Create suspended process (no resume)

    inj           inj shellcode -f file.bin -p 2300 --- <args>         Inject shellcode into a process
                  inj dll-reflective -f file.dll -p 2300               Inject reflective DLL into a process
                  inj donut -f file -p 2300 --- <args>                 Inject multiple payloads types via donut

    --alloc       --alloc section                                      Use section allocation
                  --alloc stomping [--stomp-dll "name.dll"]            Use stomping allocation
                  [!] Avaliable in inj and migrate 

    --encoder     --encoder sgn                                        Use sgn encoder
                  [!] inj donut/shellcode only

PROCESS
-------------------------------------------------------------------------------------------------------------------------

    proc          proc info                                                       Current process summary
                  proc info [modules|privileges|full]                             Show specific process information
                  proc info --pid <pid> privileges                                Privilege list for PID
                  proc info --pid <pid>                                           Process summary for PID
                  proc privileges --name SeDebugPrivilege -st [on|off]            Enable or disable a privilege
                  proc [kill|suspend|resume] --pid <pid>                          Change process state by PID

    tokens        tokens                                                          Current token
                  tokens grab --pid 1000                                          Grab token from a process into vault
                  tokens list                                                     List saved vault tokens
                  tokens impersonate --id 0                                       Impersonate a vault token
                  tokens remove --id 0 [--all]                                    Remove vault token
                  tokens forge --domain name --user jhon --pass 123456            Create a forged logon session
                  tokens revert                                                   Stop impersonating (RevertToSelf)

    runas         runas --domain name -u jhon -p 123 --path cmd.exe --- <args>    Execute a command as a different user
