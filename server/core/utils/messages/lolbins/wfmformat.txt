ABOUT
    Command-line tool used for pretty-print a dump file generated by
    Message Farm Analyzer tool. LOLBAS documents proxy execution of
    binary.

USAGE:
    WFMFormat.exe

EXAMPLES:
    WFMFormat.exe

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    WFMFormat.exe
