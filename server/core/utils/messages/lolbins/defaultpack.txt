ABOUT

    on the Microsoft website. It gets downloaded when the user forgets
    to uncheck the option to set Bing as the default search provider.
    LOLBAS documents can be used to execute stagers, binaries, and other
    malicious commands.

USAGE:
    DefaultPack.EXE /C:"{CMD}"

EXAMPLES:
    DefaultPack.EXE /C:"{CMD}"

NUKERAT FLAGS:

    -bg             Fork and run without waiting for output
