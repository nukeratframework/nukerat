ABOUT
    Console Window host for Windows Terminal. LOLBAS documents use
    OpenConsole.exe as a proxy binary to evade defensive
    counter-measures.

USAGE:
    OpenConsole.exe {PATH:.exe}

EXAMPLES:
    OpenConsole.exe {PATH:.exe}

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    OpenConsole.exe {PATH:.exe}
