ABOUT
    Windows Terminal. LOLBAS documents use wt.exe as a proxy binary
    to evade defensive counter-measures.

USAGE:
    wt.exe {CMD}

EXAMPLES:
    wt.exe {CMD}

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    wt.exe {CMD}
