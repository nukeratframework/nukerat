ABOUT
    Trace log generation tool for Media Foundation Tools. LOLBAS
    documents local execution of cmd.exe as a subprocess of Mftrace.exe.

USAGE:
    Mftrace.exe {PATH:.exe}

EXAMPLES:
    Mftrace.exe {PATH:.exe}

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    Mftrace.exe {PATH:.exe}
