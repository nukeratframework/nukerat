ABOUT
    Command-line tool for running Message Passing Interface (MPI)
    applications. LOLBAS documents executing commands under a trusted,
    Microsoft-signed binary.

USAGE:
    mpiexec.exe {CMD}

EXAMPLES:
    mpiexec.exe {CMD}

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    mpiexec.exe {CMD}
