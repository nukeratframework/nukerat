ABOUT
    Device credential deployment helper.
    Hides the console window so background cmd or similar runs with less
    visible UI.

USAGE:
    DeviceCredentialDeployment

EXAMPLES:
    DeviceCredentialDeployment

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    DeviceCredentialDeployment
