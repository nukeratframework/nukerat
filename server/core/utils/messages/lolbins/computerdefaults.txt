ABOUT
    Default apps settings executable.

    elevated code without a prompt.

USAGE:
    ComputerDefaults.exe

EXAMPLES:
    ComputerDefaults.exe

NUKERAT FLAGS:
    -w <seconds>    Maximum wait time until timeout
    -bg             Fork and run without waiting for output

    Example:
    ComputerDefaults.exe
