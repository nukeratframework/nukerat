# Overview

Raw logic of the SGN encoder. `encoder.rs` is the pipeline, `cipher.rs` and `decoder.rs` are the ADFL and schema cipher plus the decoder stubs, `obfuscate.rs` is the garbage instructions, `registers.rs` is the register pools, `util.rs` is the CLI helpers, `main.rs` is the command line, and `lib.rs` is the library entry.
